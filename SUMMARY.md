# WinQI: repository state

Canonical public repository: `twerdster/winqi`. This project preserves coded-beacon research known as WinQI/Winqi/Winky and maintains a separate updated implementation. Keep original research, updated software, and new demonstration media distinct.

The project README leads with the technology, demonstration, research lineage and results, then runnable decoder commands and code navigation. Recovery counts, hashes, script caveats and media handoff details belong in the supporting guides. The original Winqi paper is arXiv:1708.05625v1 (18 August 2017, Aaron Wetzler and Ron Kimmel). CoBe is the expanded, retitled v3 of the same arXiv record (21 April 2020, Roman Rabinovich, Ibrahim Jubran, Aaron Wetzler and Ron Kimmel), published at IEEE CASE 2020. Use explicit versioned paper links. CoBe's full public camera/localization/firmware application remains linked upstream rather than copied wholesale. Attribute hardware results to that paper and its experimental conditions; the new decoder checks and synthetic animation measure a separate scope.

The original publication subset is 62 exact files: 16 MATLAB/MEX source files, 43 saved tables, and two David Cumin LCS variants plus their BSD notice. docs/ORIGINAL_SOURCE_MANIFEST.json records relative origins, original/published hashes, exclusions, and the 19 cyclic MAT files byte-identical to the public CoBe archive. docs/ORIGINAL_TABLE_INVENTORY.json records reviewed numeric table schemas.

Important revision difference: recovered genCodesCyclic.m writes code-list indexes to a 2^n dictionary, but actual saved MAT dictionaries have 2^(n+1) entries and store raw numeric code + 1, with 0 unknown. CodeCyclic10 has a different constant-code selection from many other files. Do not claim every archived table is regenerated by the exact archived script or the new implementation.

Original code has no new blanket license. The scoped LCS BSD notice and public CoBe MIT notice are retained. Omitted MathWorks code and other helpers without a recovered grant remain excluded. Private research notes/disclosures, paper/mail archives, raw backup containers, and separate private Android capture work remain outside the public release.

Original validation: all 62 hashes pass, 40 MAT files have numeric/struct-numeric content, 3 DAT files have binary-text content, and 17 MATLAB files pass MISS_HIT 0.9.44 parsing with one preserved genBalls block-comment warning. Originals were not executed. Updated code/tests and newly generated media have separate scope/results and must not be advertised as camera/pose/SLAM validation.

The updated standard-library Python core exposes codebook/decode/simulate CLI commands. Its fixed-width active genNoise model uses disjoint cyclic neighborhoods and explicit constant-candidate policy. Fifteen tests cover 5,070 physical single-fault streams, stream/CLI/unknown handling, trace replay, and exact regeneration of five saved dictionaries using a separate older variable-length reference model. The default trace has 720 observation events, 72 warmup events and 648 correct post-warmup identifications. Static observed sources are not rejected by this core: the all-zero window is a valid noisy neighbor of its first code. Track association and binary observations are inputs.

The new media use a generated room/mannequin, six animated LEDs, orbit/head/hand projections and actual decoder-output overlays. Dani Epstein’s 2016 final Winqi animation was recovered as a private visual reference; its original Blender ZIP handoff link is currently inaccessible. No original Dani scene, reference image, email or invoice is redistributed. New render/compose scripts, media and their scoped MIT notices are separate from the historical archive. Renderer scratch data and source-evidence paths are recorded in the private task handoff.

Media validation confirms a 12-second H.264 video at 1600 by 900, 30 fps and 360 decoded frames. All 360 projection records and 2,160 LED states match an independent Blender probe. Poster and five encoded frame samples were reviewed; 390 sampled HUD bit states match the receiver trace. The self-contained published blend uses a portable CPU setting, contains no embedded scripts/drivers/external assets, and retains its camera/LED keyframes. Hash/input bindings are recorded in docs/DEMO_VALIDATION.json and checked by scripts/verify_demo.py. Google Chrome played all 360 frames to the 12-second end without a decode error. Seven Markdown guides rendered at 390/1440 pixels without overflow; their relative links and images resolved.

The archive keeps original line endings via .gitattributes; fifteen exact original paths have whitespace exceptions, while new code/docs keep normal checks. GitHub Actions runs original hash checks, core/fixture tests and a CLI simulation on Python 3.10 and 3.14. It does not render or run historical apps. Source, tests and media are public on twerdster/winqi main, with both CI versions passed; the academic website links this repository beside the CoBe paper. For later publication changes, verify the public commit and relevant checks. Before each commit, review this file and SKILL.md and synchronize status, commands, outputs, and validation claims.
