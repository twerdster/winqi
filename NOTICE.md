# Attribution and license scope

The historical WinQI MATLAB experiments and code tables were recovered from Aaron Wetzler's preserved coded-beacon research materials. This source release adds no blanket license and does not claim that every historical helper was authored by one person.

- **Historical algorithm/experiment files and noncyclic tables:** preserved as research source with their original bytes and comments. No new license is assigned.
- **David Cumin LCS helper:** the packaged and modified variants retain their original author attribution. The recovered [2009 two-clause BSD notice](source/original/third_party/lcs/LICENSE.txt) accompanies both variants. Preserve that notice on redistribution.
- **Nineteen cyclic MAT tables:** each is byte-identical to the same filename in `CodeCyclic.zip` from the public [baklawe/CoBe repository](https://github.com/baklawe/CoBe), pinned at `576d6f9ba833ec16c46e0645141b9a0e92e4dc55`. That repository carries the MIT license, copyright 2020 baklawe. The full [CoBe notice](LICENSES/CoBe-MIT.txt) is retained for these already-public copies. This does not extend that license to unrelated private-backup files.
- **New updated code and new media:** created in 2026 by Aaron Wetzler with coding-agent assistance, with separate scoped MIT notices in updated/ and media/. No historical third-party license is replaced. The new media credit Dani Epstein’s earlier animation as a visual reference and include no original Dani assets.

The related CoBe paper credits **Roman Rabinovich, Ibrahim Jubran, Aaron Wetzler, and Ron Kimmel**. CoBe's application source and firmware remain linked upstream rather than copied wholesale into this archive.

Obvious third-party source without a recovered redistribution grant, including the copied MathWorks HMM routine, is excluded. Private correspondence, invention disclosures, account details, paper archives, raw backup containers, and unrelated code are not included.
